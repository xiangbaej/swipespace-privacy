SwipeSpace 개인정보처리방침

운영자: SwipeSpace · 시행일: 2026년 9월 25일 · 적용 앱 버전: 0.6.0

1. 한눈에 보는 개인정보 처리 요약

  • SwipeSpace는 사용자가 허용한 기기 내 공유 저장공간의 파일을 찾아 보여줍니다.
  • 파일 정보와 사진·영상·PDF 미리보기는 기기에서 처리합니다. 앱에는 자체 서버와 인터넷 권한이 없으며, 개발자가 이 정보를 외부로 수집하지 않습니다.
  • 유지 결정과 진행 중인 정리 세션의 일부 정보는 기기 내 앱 전용 공간에 남습니다. 삭제 방법은 7항에 설명합니다.
  • 파일을 넘기는 것만으로 삭제되지 않습니다. Review 화면에서 사용자가 실행한 삭제만 시도합니다.
  • 계정, 광고, 분석·크래시 보고 SDK, 외부 AI API는 없습니다.

2. 적용 범위 및 개발자·문의 정보

이 방침은 Android 앱 SwipeSpace의 현재 버전(0.6.0)에 적용됩니다. 앱의 운영자 표시명은 SwipeSpace이며, 개인정보 문의 이메일은 sasam712@gmail.com입니다. 이 공개 웹페이지는 방침을 읽을 수 있도록 제공되며, 아래의 앱 데이터 처리 설명과 웹페이지 호스팅 사업자의 접속 정보 처리는 구분됩니다(15항).

3. 기기에서 접근·처리하는 정보

앱은 사용자가 접근을 허용한 공유 저장공간의 파일명, 경로 또는 URI, 크기, 수정 시각, MIME 유형(제공되는 경우), 읽기·삭제 가능 여부를 확인합니다. 사진·영상·PDF는 현재 카드와 가까운 다음 카드의 미리보기를 기기에서 읽을 수 있습니다. 다른 파일은 유형·이름·크기·위치 중심으로 표시합니다.

위험 표시에는 파일명·경로·확장자에 대한 로컬 규칙을 사용합니다. 파일 내용을 AI나 외부 서비스에 보내 판단하지 않습니다. 사용자가 고른 KEEP 결정, 현재 세션의 후보와 실행 결과, 선택한 폴더의 접근 권한 및 사용법 안내 확인 상태는 기기에 보관될 수 있습니다.

4. 정보 처리 목적

파일 크기순 탐색, 파일 카드와 미리보기 표시, 위험 가능성 안내, KEEP 파일의 재노출 방지, 삭제 후보와 Undo·Review 상태 유지, 사용자가 명시적으로 실행한 삭제 및 결과 확인에 사용합니다. 파일 정보는 광고, 사용자 프로필 작성, 외부 AI 학습에 사용하지 않습니다.

5. 외부 전송·수집·공유 여부

현재 앱에는 자체 서버, 계정, 파일 업로드 기능 및 INTERNET 권한이 없습니다. 개발자는 앱이 읽은 파일 내용·파일명·미리보기·선택 기록을 기기 밖으로 전송받거나 수집하지 않으며, 이를 판매하거나 제3자에게 공유하지 않습니다. 기기 안에서만 이루어지는 접근·처리는 Google Play Data Safety의 기기 밖 전송을 뜻하는 “수집”과 구분됩니다. 사용자가 직접 다른 앱에서 파일 열기를 선택한 경우는 9항과 15항을 참고하세요.

6. Android 저장공간 권한 및 제한 모드

전체 모드는 여러 공유 폴더의 큰 파일을 찾고 사용자가 직접 관리하도록 Android의 “모든 파일에 대한 접근”(MANAGE_EXTERNAL_STORAGE)을 요청합니다. 이 권한은 선택할 수 있으며, 허용하지 않아도 Android 폴더 선택기(Storage Access Framework)로 사용자가 지정한 로컬 폴더를 분석하는 제한 모드를 이용할 수 있습니다. 폴더 선택 시 Android가 허용한 읽기·쓰기 범위만 사용합니다.

앱은 Android/data, Android/obb 등 보호 영역을 우회하지 않으며, 접근할 수 없거나 크기를 확인할 수 없는 항목은 건너뜁니다. 권한을 철회하면 해당 범위의 스캔 또는 작업을 계속할 수 없습니다.

7. 기기 내 저장·보유기간·삭제 방법

KEEP한 파일의 식별 정보(경로 또는 URI·크기·수정 시각 조합)와 선택 시각은 앱 전용 저장공간에 보관되어 다음 스캔에서 다시 보여주지 않는 데 사용됩니다. 앱 데이터 삭제 또는 앱 제거 전까지 남을 수 있습니다. 진행 중인 정리 세션에는 스캔 후보의 파일 정보, 선택 및 삭제 결과가 저장되며, 완료 후 ‘완료’ 또는 ‘계속 정리’로 세션을 종료하면 제거됩니다. 앱이 작업 중 종료되면 미완료 세션 정보가 남을 수 있습니다.

미리보기는 메모리에서 처리하며 별도 디스크 썸네일 캐시를 만들지 않습니다. 사용법 안내 확인 여부는 기기에 저장됩니다. 선택한 폴더의 지속 접근 권한은 Android가 관리하며, 다른 폴더를 선택하면 앱은 이전 폴더 권한을 해제합니다. 앱 데이터의 클라우드 백업과 기기 이전은 앱 설정에서 제외합니다.

기기 내 앱 기록 전체를 지우려면 Android 설정에서 SwipeSpace의 앱 데이터를 삭제하거나 앱을 제거할 수 있습니다. 이는 공유 저장공간에 있는 원본 파일을 삭제하지 않습니다. 앱 계정이 없으므로 계정 삭제 절차는 없습니다.

8. 파일 삭제와 복구에 관한 설명

왼쪽 스와이프나 ‘삭제’ 선택은 삭제 후보 등록일 뿐이며 파일을 즉시 변경하지 않습니다. 위험 가능성이 있는 파일은 추가 확인 또는 보호 해제가 필요합니다. 실제 삭제는 Review 화면에서 사용자가 후보를 검토하고 명시적으로 실행할 때만 시도합니다. 실행 직전 파일 상태와 권한을 다시 확인하며, 변경되었거나 접근할 수 없는 파일은 삭제 실패로 처리합니다.

파일 유형과 접근 방식에 따라 Android의 미디어 삭제 확인 요청, 문서 제공자의 삭제 기능 또는 공유 저장공간 파일 삭제를 사용합니다. 삭제 후 복구 가능성은 Android 버전, 파일 유형, 저장소 제공자 및 별도 백업 여부에 따라 다릅니다. SwipeSpace는 실행된 삭제를 자체적으로 복원하는 기능을 제공하지 않습니다. 실패한 파일의 크기는 확보 완료 용량에 포함하지 않습니다.

9. 제3자 제공

개발자가 앱에서 처리한 파일 정보나 사용 기록을 제3자에게 제공하는 기능은 없습니다. 다만 사용자가 ‘파일 열기’를 직접 선택하면 Android가 사용자가 선택한 다른 앱에 해당 파일의 읽기 접근을 부여합니다. 이는 사용자 요청에 따른 기기 내 전달이며, 선택한 앱의 후속 처리는 그 앱의 방침을 따릅니다.

10. 개인정보 처리위탁

현재 Android 앱에서 접근한 파일 정보·선택 기록의 처리를 외부 사업자에게 위탁하지 않습니다. 방침 웹페이지의 호스팅은 앱의 파일 데이터 처리위탁과 별개입니다(15항).

11. 국외 이전

현재 Android 앱은 파일·미디어 정보와 기기 내 선택 기록을 외부로 전송하지 않으므로 개발자에 의한 해당 앱 데이터의 국외 이전은 없습니다. 공개 방침 웹페이지에 접속할 때 발생하는 브라우저 통신은 앱의 파일 전송과 별개입니다(15항).

12. 광고·분석·쿠키·추적 기술

현재 앱에는 광고 SDK, 사용 분석 SDK, 크래시 보고 SDK, 외부 AI API 및 앱 내 웹 추적 기능이 없습니다. 앱은 쿠키를 사용해 사용자를 추적하지 않습니다. 공개 방침 웹페이지는 외부 스크립트나 추적 코드를 포함하지 않지만, 호스팅 사업자의 웹 접속 처리까지 앱이 통제한다는 뜻은 아닙니다.

13. 안전성 확보 조치

앱은 Android 권한으로 허용된 파일에만 접근하고, 기기 내 기록을 앱 전용 저장공간에 보관하며, 앱 데이터 백업·기기 이전을 제외합니다. 미리보기의 별도 디스크 캐시를 만들지 않고, 파일 삭제 전에는 크기·수정 시각·접근 가능 여부를 다시 확인합니다. 보호 영역을 우회하지 않습니다. 자체 서버로 파일 정보를 전송하지 않으므로 앱 파일 정보에 대한 서버 전송 구간은 없습니다. 이러한 조치가 모든 기기·운영체제 환경에서 절대적인 안전을 보장한다는 뜻은 아닙니다.

14. 사용자의 선택권과 권한 철회

전체 파일 접근 대신 제한 폴더 모드를 선택할 수 있습니다. Android 설정에서 전체 파일 접근 권한을 철회하거나, 앱 데이터를 삭제해 앱의 로컬 기록과 저장된 설정을 지울 수 있습니다. 다른 로컬 폴더를 고르면 이전 폴더 접근 권한이 해제됩니다. 삭제 후보는 실행 전 Review에서 제외할 수 있습니다. 최근 결정에 표시되는 Undo는 해당 결정을 되돌리며, 실제 삭제 실행 후의 복원 수단은 아닙니다.

15. 외부 앱·Android 시스템과의 상호작용

폴더 선택과 권한 부여는 Android 시스템 화면을 사용합니다. 관리되는 미디어의 삭제에는 Android가 추가 확인을 요청할 수 있습니다. 사용자가 파일 열기를 선택하면 선택한 외부 앱에 해당 파일의 읽기 접근이 전달됩니다. SwipeSpace는 그 앱의 이후 처리 방식을 제어하지 않습니다.

공개 개인정보처리방침은 GitHub Pages에서 제공됩니다. 웹브라우저로 이 페이지에 접속하면 호스팅 사업자가 웹 접속 정보를 자체 방침에 따라 처리할 수 있습니다. 이는 SwipeSpace Android 앱이 기기의 파일이나 사용 기록을 GitHub에 업로드한다는 의미가 아닙니다.

16. 아동 관련 사항

현재 앱에는 계정 생성이나 연령 확인 기능이 없습니다. Google Play의 대상 연령과 아동 대상 여부는 출시 설정에서 아직 확정되지 않았으므로, 출시 전 관련 고지·동의 요건을 검토해 이 항목을 확정해야 합니다. 확정되지 않은 연령 제한이나 아동 데이터 처리 방식을 임의로 선언하지 않습니다.

17. 처리방침 변경 및 시행일
