SwipeSpace 개인정보처리방침

운영자: SwipeSpace
적용 버전: 0.6.0 · 작성일: 2026년 9월 24일

1. 접근하는 정보와 사용 목적

SwipeSpace는 사용자가 접근을 허용한 공유 저장공간에서 큰 파일을 찾아 직접 유지하거나 삭제하도록 돕습니다. 파일명, 경로 또는 URI, 크기, 수정 시각, 유형, 읽기·삭제 가능 여부를 기기에서 확인합니다. 현재 카드와 다음 카드의 사진·영상·PDF 미리보기를 기기에서 읽을 수 있습니다. 중요한 파일일 가능성은 파일명·경로·확장자 규칙으로 표시합니다.

2. 외부 전송·수집·공유

SwipeSpace에는 서버, 계정, 파일 업로드, 광고, 분석 SDK, 외부 AI API가 없습니다. 앱은 인터넷 권한을 요청하지 않습니다. 파일 내용, 파일명, 미리보기, 사용 기록을 기기 밖의 개발자 서버로 전송하거나 개발자가 수집하지 않습니다. 개발자가 이 정보를 제3자에게 판매하거나 공유하지 않습니다. 사용자가 직접 다른 앱에서 파일 열기를 선택하는 경우는 아래 5항과 같습니다.

3. 기기 내 저장·보관과 안전한 처리

유지한 파일의 식별 정보와 선택 시각, 현재 정리 세션의 파일 정보·선택·삭제 결과를 Android 앱 전용 저장공간에 저장합니다. 유지 기록은 앱 데이터 삭제 또는 앱 제거 전까지 남을 수 있습니다. 세션 기록은 완료 후 완료/계속 정리 동작으로 종료하면 제거됩니다. 미리보기는 메모리에서 처리하며 별도 디스크 썸네일 캐시를 만들지 않습니다. 사용자가 선택한 로컬 폴더의 Android 접근 권한과 사용법 안내 확인 여부도 기기에 저장됩니다.

파일 접근은 Android가 허용한 권한 범위 안에서 이루어집니다. 앱 전용 데이터의 클라우드 백업 및 기기 이전은 설정으로 제외합니다. 외부 전송을 하지 않으므로 파일 정보의 네트워크 전송 과정은 없습니다.

4. 권한과 사용자 선택

모든 파일 접근은 여러 폴더의 대용량 파일을 탐색하고 관리하기 위한 선택 권한입니다. 허용하지 않아도 Android 폴더 선택기로 지정한 로컬 폴더를 이용할 수 있습니다. Android의 보호 영역 접근을 우회하지 않습니다. 권한은 Android 설정에서 해제할 수 있습니다.

5. 다른 앱에서 파일 열기와 삭제

사용자가 파일 열기를 직접 선택하면 Android에서 선택한 다른 앱에 해당 파일의 읽기 접근을 허용합니다. 이후 그 앱의 처리에는 해당 앱의 개인정보처리방침이 적용됩니다. 파일을 넘기는 것만으로 삭제하지 않습니다. Review 화면에서 명시적으로 실행한 파일만 삭제하며, 실패한 파일의 용량을 확보한 것으로 계산하지 않습니다. 실행된 삭제는 SwipeSpace에서 복구할 수 없을 수 있습니다.

6. 데이터 삭제와 계정

Android 설정에서 SwipeSpace의 앱 데이터를 지우거나 앱을 제거하면 기기 내 앱 기록을 제거할 수 있습니다. 이 작업은 사용자의 공유 저장공간 원본 파일을 삭제하지 않습니다. SwipeSpace에는 계정 생성·로그인 기능이 없으므로 삭제할 앱 계정도 없습니다.
